Cloud Credits Tracker ☁️💳
 
A lightweight web application designed to help students, developers, and teams monitor cloud credits, manage service vouchers, and track spending across major cloud providers (AWS, Google Cloud, Azure, and Oracle Cloud).
 
---
 
## 🚀 Overview
 
Managing multiple developer programs, hackathon credit vouchers, and student benefit programs often leads to unexpected expiration or accidental billing overages. **Cloud Credits Tracker** provides a centralized, intuitive interface to log granted credits, calculate burn rates, and receive early expiration alerts.
 
---
 
## ✨ Features
 
- **Multi-Cloud Support**: Track credits across AWS Educate, Google Cloud Innovators/Credits, Azure for Students, and Oracle Cloud Free Tier.
- **Voucher & Balance Management**: Log promo codes, grant dates, expiry dates, and remaining balances.
- **Burn-Rate & Usage Estimates**: Estimate daily consumption to avoid premature depletion.
- **Expiry Warnings**: Highlight credits approaching expiration within 30, 15, and 7 days.
- **Responsive Dashboard**: Clean interface built with modern JavaScript and HTML/CSS.
 
---
 
## 🛠️ Tech Stack
 
- **Frontend**: HTML5, CSS3, Modern JavaScript (ES6+)
- **Storage / Persistence**: LocalStorage / JSON-based configuration (or connected backend API)
- **Styling**: Responsive Flexbox/Grid layout
